# 🛒 E-Commerce Customer Purchase Prediction

An end-to-end Machine Learning project that predicts whether an e-commerce website session will result in a purchase. This project explores customer browsing behavior and demonstrates a complete classification workflow, from data inspection and cleaning to model evaluation.

## 🎯 Project Objectives

- Understand and inspect a real-world e-commerce dataset.
- Identify and investigate data quality issues.
- Perform Exploratory Data Analysis (EDA).
- Apply appropriate data cleaning and preprocessing techniques.
- Engineer useful features for classification.
- Build and compare multiple Machine Learning models.
- Evaluate model performance using appropriate classification metrics.
- Interpret results and identify potential business insights.

## 📊 Dataset

**Dataset:** Online Shoppers Purchasing Intention Dataset

**Source:** UCI Machine Learning Repository

**Official link:** https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset

The dataset contains website-session information, including page activity, visitor characteristics, and other session-related measurements.

The target variable, `Revenue`, indicates whether a session resulted in a purchase.

## 📈 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The evaluation process will consider the class imbalance in purchase outcomes.
